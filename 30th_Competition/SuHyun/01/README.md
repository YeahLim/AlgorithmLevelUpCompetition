# [프로그래머스- Lv2] 마법의 엘레베이터

## ⏰**time**
20분

## :pushpin: **Algorithm**
BFS

## ⏲️**Time Complexity**
$O(N)$

## :round_pushpin: **Logic**
- 현재 자리수가 6~9면 10을 쓰는게 이득
- 현재 자리수가 0~4면 0을 쓰는게 이득
- 현재 자리수가 5면 다음 자리수를 확인한다

## :black_nib: **Review**
- 파이썬은 //로 나머지 연산을 할 수 있다
