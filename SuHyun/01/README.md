# [프로그래머스 - level 2] 숫자 카드 나누기

## ⏰  **time**
20분

## :pushpin: **Algorithm**
최대공약수

## ⏲️**Time Complexity**
$O(N^2)$

## :round_pushpin: **Logic**
- 모든 수에 나눠지는 수는 최대공약수이므로 배열 중 1개의 최대공약수를 구한 뒤 나머지 배열에 나머지지 않는 숫자를 찾으면 된다
