# [프로그래머스 - level 2] 점프와 순간 이동

## ⏰  **time**
10분

## :pushpin: **Algorithm**
완전탐색

## ⏲️**Time Complexity**
$O(N)$

## :round_pushpin: **Logic**
- *2, +1의 완전탐색 같지만 *2는 건전지가 소비되지 않으므로 *2를 무한히 하고 부족한 부분만 +1를 하면 된다
